# Contributing to PDF Utility Toolkit Pro

First off, thank you for considering contributing to **PDF Utility Toolkit Pro**! 🎉

This project is built using strictly **Python, HTML, CSS, and Vanilla JavaScript** with a strong emphasis on privacy, local-first performance, and clean code.

---

## Code of Conduct
Please be polite, respectful, and collaborative. Treat everyone with empathy and kindness.

---

## How Can I Contribute?

### 1. Reporting Bugs
* Check existing [GitHub Issues](https://github.com/Harsh79665/PDF-Toolkit-Pro/issues) before opening a new one.
* Include detailed steps to reproduce the issue, sample inputs (ensure they contain no private data), and error stack traces.

### 2. Suggesting Enhancements
* Open an issue with the label `enhancement`.
* Clearly describe the workflow improvement and why it would benefit users.

### 3. Pull Requests
1. Fork the repo and create a new feature branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```
2. Ensure you adhere to the project's strict stack: **Python 3.9+, HTML5, Vanilla CSS3, Vanilla ES6+ JavaScript**. (No React, Vue, TypeScript, or Node dependencies).
3. Run the automated test suite to ensure all tests pass:
   ```bash
   python -m pytest
   ```
4. Commit your changes with a descriptive commit message:
   ```bash
   git commit -m "feat: add support for page label extraction"
   ```
5. Push to your branch and submit a Pull Request!
