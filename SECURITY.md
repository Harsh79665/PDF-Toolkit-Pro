# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a high priority for **PDF Utility Toolkit Pro**. All PDF operations are handled locally and non-destructively on your machine without external cloud telemetry.

If you discover a security vulnerability or potential exploit:

1. **Do not create a public GitHub issue.**
2. Send an email to the project maintainer: **Harsh Patel** (via GitHub profile [@Harsh79665](https://github.com/Harsh79665)).
3. Include details of the vulnerability, steps to reproduce, and sample input files if applicable.
4. Maintainers will acknowledge receipt within 48 hours and work with you to test and release a security patch.

Thank you for helping keep PDF Utility Toolkit Pro secure for everyone!
